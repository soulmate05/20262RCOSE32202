## 1. 운영체제의 역할

운영체제는 CPU, 메모리, 저장장치와 같은 하드웨어 자원을 관리하고 프로그램에 실행 환경을 제공합니다. 여러 프로그램이 자원을 공유할 수 있도록 조정하며, 보호와 추상화를 통해 프로그램이 하드웨어를 안전하고 일관된 방식으로 사용할 수 있게 합니다.

## 2. 프로세스와 스레드

프로세스는 실행 중인 프로그램으로, 주소 공간과 실행에 필요한 자원을 가집니다. 스레드는 프로세스 안의 실행 흐름입니다. 같은 프로세스의 스레드는 코드와 데이터 등의 자원을 공유하지만, 각자 레지스터 상태와 스택을 가집니다.

## 3. 시스템 콜과 실행 모드

사용자 프로그램은 시스템 콜을 통해 파일 접근이나 프로세스 생성 같은 커널 서비스를 요청합니다. 사용자 모드에서는 특권 명령의 실행이 제한됩니다. 시스템 콜 진입 시 커널 모드로 전환하여 요청을 처리하고, 처리 결과를 가지고 사용자 모드로 돌아옵니다.

## 4. 인터럽트와 문맥 교환

인터럽트는 타이머나 입출력 장치 등의 사건을 CPU에 알리는 수단입니다. 문맥 교환은 실행 중인 작업의 상태를 저장하고 다른 작업의 상태를 복원하는 과정입니다. 타이머 인터럽트는 선점형 스케줄링의 계기가 될 수 있지만, 모든 인터럽트가 다른 프로세스로의 문맥 교환을 일으키는 것은 아닙니다.

## 5. CPU 스케줄링

| 방식 | 기본 동작 | 주요 특징 |
| --- | --- | --- |
| FCFS | 도착한 순서대로 실행 | 긴 작업 뒤의 짧은 작업이 오래 기다릴 수 있음 |
| 비선점 SJF | 준비된 작업 중 예상 CPU 버스트가 가장 짧은 작업 선택 | 실행 시간 예측이 필요하며 긴 작업의 기아 가능성이 있음 |
| Round Robin | 정해진 시간 할당량만큼 번갈아 실행 | 시간 할당량이 작을수록 문맥 교환 부담이 커질 수 있음 |

반환 시간 = 완료 시각 - 도착 시각입니다. 대기 시간은 준비 큐에서 기다린 시간의 합이며, 응답 시간은 도착부터 최초 CPU 실행까지의 시간입니다.

## 6. 동기화와 임계 구역

경쟁 상태는 공유 데이터에 대한 실행 순서에 따라 결과가 달라지는 상황입니다. 임계 구역은 공유 자원에 접근하는 코드 영역입니다. 뮤텍스나 세마포어 등의 동기화 수단으로 접근을 조정할 수 있으며, 공유 자원의 보호 범위와 잠금 획득 순서를 함께 고려해야 합니다.
