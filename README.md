## 1. 운영체제의 역할

운영체제는 CPU, 메모리, 저장장치와 같은 하드웨어 자원을 관리하고 프로그램에 실행 환경을 제공합니다. 여러 프로그램이 자원을 공유할 수 있도록 조정하며, 보호와 추상화를 통해 프로그램이 하드웨어를 안전하고 일관된 방식으로 사용할 수 있게 합니다.

## 2. 프로세스와 스레드

프로세스는 실행 중인 프로그램으로, 주소 공간과 실행에 필요한 자원을 가집니다. 스레드는 프로세스 안의 실행 흐름입니다. 같은 프로세스의 스레드는 코드와 데이터 등의 자원을 공유하지만, 각자 레지스터 상태와 스택을 가집니다.
